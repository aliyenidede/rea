# plans/

Active work. One directory per unit of planned work, holding up to four files: `brief.md`,
`spec.md`, `plan.md`, `todo.md`.

Naming rule: numbered directories, `NNNN-<slug>/` — uniqueness comes from the slug, not the number,
so parallel branches minting the same number with different slugs merge cleanly.

See [`core/rea-schema.md`](../../core/rea-schema.md) for the full naming rules and the
`plan.md`/`todo.md` formats.
