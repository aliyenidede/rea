# decisions/

Architecture decision records — why. One file per decision, `NNNN-<slug>.md`, numbered
sequentially.

Naming rule: numbered, **append-only** — a new decision is always a new file; an existing decision
is never edited to change its outcome. A later decision that replaces an earlier one supersedes it
via a new file (the old one is marked superseded), never by overwriting.

See [`core/rea-schema.md`](../../core/rea-schema.md) for the full naming and collision rules.
