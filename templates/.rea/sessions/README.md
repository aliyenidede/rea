# sessions/

Episodic notes — what happened, when. One file per work session.

Naming rule: **timestamped**, `YYYY-MM-DD-HHMM-<slug>.md` — the timestamp makes the filename
naturally unique, so no collision guard is needed for this type.

See [`core/rea-schema.md`](../../core/rea-schema.md) for the full naming and collision rules.
